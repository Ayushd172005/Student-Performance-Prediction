# 🎓 Student Performance Prediction – Machine Learning Project

A **machine learning–based student performance prediction system** that estimates final academic scores using **demographic data, attendance, and study behavior**.  
This project demonstrates practical application of **data preprocessing, regression modeling, and performance evaluation** using Python.

---

## 📌 Project Overview

Student academic performance is influenced by multiple factors such as attendance, study hours, and prior academic results.  
This project uses **supervised machine learning (regression)** to predict a student’s final score based on these inputs.

The goal is to help educational institutions and educators **identify performance patterns early** and support data-driven academic interventions.

---

## 🚀 Features

- 📊 Predict final student scores using regression models  
- 🧮 Uses demographic and academic features  
- 🔍 Feature importance analysis using model coefficients  
- 📈 Actual vs Predicted score visualization  
- ⚡ Clean and efficient data preprocessing pipeline  
- 📱 Fully executable on Google Colab  

---

## 🛠️ Tech Stack

- **Python**
- **pandas** – Data manipulation
- **NumPy** – Numerical computing
- **scikit-learn** – Machine learning & regression
- **Matplotlib & Seaborn** – Data visualization

---

## 🧠 Machine Learning Approach

- **Model Used:** Linear Regression  
- **Problem Type:** Supervised Regression  
- **Target Variable:** Final Student Score  
- **Evaluation Metrics:**
  - Mean Absolute Error (MAE)
  - Mean Squared Error (MSE)
  - Root Mean Squared Error (RMSE)
  - R² Score
